## ✦ Tech

Static single-page site — HTML5, vanilla CSS + Tailwind, vanilla JS (ES modules), and OGL/WebGL
for interactive visuals. Zero build step.

## ✦ Run Locally

Requires Python 3.x or Node.js.

```bash
npm start
# or
python -m http.server 8080
```

Then open `http://localhost:8080`.

## ✦ Deploy

Completely static — deploys to any edge host (Vercel, Netlify, GitHub Pages) with the publish
directory set to `/`.
